# Petit Miracle ✨

Une petite page web qui propose un geste bienveillant de moins d'une minute, un seul à la fois.

- Filtres : pour moi, pour quelqu'un, dehors, pour le corps
- Minuteur pour certains gestes
- Compteur d'étoiles du jour, stocké localement (rien n'est envoyé)

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune dépendance, aucune compilation.
Déployable tel quel sur n'importe quel hébergement statique.
